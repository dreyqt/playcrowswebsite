# Asset sources

## Owner-supplied PlayCrows source

Brand marks, announcement artwork, referral-event artwork, feature imagery, and the original Night Crows cinematic video came from `playcrowswebsite(1).zip`. The cinematic was re-encoded for web delivery. Its still poster was extracted from the same video. The emblem and icons are resized exports of the supplied PlayCrows logo.

## Night Crows official artwork

Source site: https://www.nightcrows.com/

The official game overview's class and game-world assets are included locally:

- `src/assets/night-crows-knight.webp`: `classes-character-3-1.webp`
- `src/assets/night-crows-mage.webp`: `classes-character-2-1.webp`
- `src/assets/night-crows-world.webp`: `gameworld-background.webp`

Official asset directory referenced by the site's overview code:
`https://gcdn.wemade.games/prod/ncgl/official/2.8.6/_next/static/images/introduce/`

No open-license statement was supplied with these official game assets. Attribution documents their source; it does not grant a license or imply affiliation. No Reborn branding, proprietary code, or Lineage artwork is included.
