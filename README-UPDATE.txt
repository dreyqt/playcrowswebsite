PLAYCROWS - V1 ACCOUNT MERGE UPDATE

V1 is now the only playable server advertised on the website.

- Removed the retired server's registration, downloads, rewards, selectors,
  promotional text, and Tower of Trial announcement and artwork.
- Preserved V1 registration and rewards; PC downloads use version 16 and Android downloads use version 18.
- Added a V2-to-V1 account guide beside the V1 server card, with navigation,
  download-section, and footer links.
- The guide uses https://www.playcrows.com/v3gethequacc/ exactly as supplied.
- Updated all five website languages and search metadata.

The account portal calls this service Merged Account Lookup. The guide explains
how to enter the original account ID and password, select Find Accounts, and
use the new account paired with the player's character to sign in to V1.
The lookup displays existing records; it does not create or change accounts.

For local development and deployment instructions, see README.md.
